# RiloStories Video Skill (free)

Make animated Roblox "In this town..." Shorts with Claude Code. **Free and fully open source (MIT licence).** No course, nothing locked, no upgrade to buy. I update it whenever I find a way to make it faster or better.

## Install
1. Download **skill.zip** (click it above, then the download button).
2. Unzip it into `C:\Users\<you>\.claude\skills\` (so you get `...\skills\roblox-story-studio\`).
   Or tell Claude Code: "install this skill from https://github.com/RiloStories/RiloStories-video-skill/raw/main/skill.zip".
   **Always ask Claude to check it is safe first**, e.g. "install this skill from <link>, but first check that it is safe to install". The code is open source: read it.
3. Open Claude Code and run the setup command: `/rss-setup`

You need: a Claude plan (Claude Code), Windows, Roblox Studio (free). Blender is optional (custom props).

Discord (help + community): https://discord.gg/k35at9FSs7
